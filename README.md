# Sandwich Shop

A small Flutter sample app that demonstrates a simple sandwich-order UI
and state management. The app is intentionally minimal and focused on UI
controls: selecting sandwich size, choosing bread type, adjusting quantity,
adding notes, and previewing the order summary.

This README documents how the app works, how to run and develop it, and
walks through the important files and widgets in the repository.

## Project overview

`sandwich_shop` is a Flutter application (single-screen demo) that lets a
user create a simple sandwich order. It intentionally keeps logic and UI
co-located in `lib/main.dart` so the app is easy to examine and modify.

- Entry point: `lib/main.dart`
- App shell: `App` widget (creates a `MaterialApp` and shows `OrderScreen`)
- Primary screen: `OrderScreen` (stateful) — contains all order controls

The app uses standard Flutter widgets (SegmentedButton, DropdownButton,
TextField, ElevatedButton) without external UI packages.

## Features

- Choose sandwich size: Six-inch or Footlong (uses `SegmentedButton`).
- Choose bread type: White, Wholemeal, Italian Herbs (via `DropdownButton`).
- Increase / decrease quantity with buttons (obeying `maxQuantity`).
- Add free-text notes (e.g., "no onions").
- Live order summary shows count, sandwich type, bread, and emoji preview.

## Quick start (Windows PowerShell)

Prerequisites:

- Flutter SDK installed and on PATH (see https://docs.flutter.dev/get-started)
- Windows: enable developer mode or have a connected device/emulator

Recommended commands (run from project root):

```powershell
# fetch dependencies
flutter pub get

# analyze the project
flutter analyze

# run the app in debug on the default device
flutter run

# run unit/widget tests
flutter test
```

If you want to run on a specific device (e.g., Windows desktop):

```powershell
flutter run -d windows
```

Notes:

- The `pubspec.yaml` requires Dart SDK `>=2.17.0 <4.0.0` (see `environment`).
- The `flutter` SDK in the `dependencies` section is used as usual.

## Development & code walkthrough

Key files and widgets (all located in `lib/main.dart`):

- `main()` — Application entry point, calls `runApp(const App())`.
- `App` — A `StatelessWidget` that returns `MaterialApp(title: 'Sandwich Shop App', home: OrderScreen(maxQuantity: 5))`.

- `enum SandwichSize { sixInch, footlong }` — model for sandwich sizes.
- `enum BreadType { white, wholemeal, italianHerbs }` — model for breads.

- `OrderScreen` (StatefulWidget)
	- Parameters: `final int maxQuantity;` (default 10, overridden to 5 by `App`).
	- State fields:
		- `_quantity` — current sandwich count (int).
		- `_notes` — free-text notes (String).
		- `_selectedSize` — `SandwichSize` selected.
		- `_selectedBread` — `BreadType` selected.
	- Controls:
		- `SegmentedButton<SandwichSize>` to toggle sizes.
		- `DropdownButton<BreadType>` to pick bread.
		- `TextField` for notes.
		- `StyledButton` instances for Add / Remove (with enable/disable logic based on `_quantity` and `maxQuantity`).

- `StyledButton` (StatelessWidget)
	- Lightweight button wrapper around `ElevatedButton` that accepts text, icon, color and an `onPressed` callback.

- `OrderItemDisplay` (StatelessWidget)
	- Renders a textual order summary and a repeated emoji preview (uses the current `quantity` to repeat '🥪').

Design notes and behavior:

- `maxQuantity` prevents the quantity from exceeding the configured maximum (default 10; `App` sets it to 5 for the demo).
- The UI uses local `setState()` for state updates — straightforward and appropriate for a small demo.
- `DropdownMenuItem` labels are generated by transforming enum names to human-friendly text.

## Troubleshooting & FAQ

- Q: The app fails to run: "No implementation found for method ..." on Windows.
	- A: Ensure the desktop platform is enabled and the correct toolchains are installed. Run `flutter doctor` and follow suggestions.

- Q: Hot reload not updating UI.
	- A: If the app is in a bad state, stop and `flutter run` again. Ensure you're running in debug mode.

- Q: I want to persist orders.
	- A: Introduce a simple local storage solution (e.g., `shared_preferences`) or a backend service and extract order logic into separate classes.
